# Paper 8 — Reproducibility

Code and reproducibility resources for an audit of
endometriosis classifier transportability and
information leakage.

## Status

Public release preparation in progress.

The computational core has been reproduced using
independently installed R and Python environments.

The complete historical null-model replay remains
partially unresolved and will be documented explicitly.
