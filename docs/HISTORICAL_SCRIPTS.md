# Historical replay scripts (not the portable core)

`replays/` contains author-local, mostly standalone scripts written during
stages 2–11. Some expect the historical `~/Desktop/paper8/endo-research`
worktree and stored GEO CEL archives; they are included as source evidence,
not as scripts that any external reviewer can run unchanged on arbitrary paths.

`diagnostics/` contains subsequent investigation of null-replay discrepancies.
The original v3.70/v3.71 null drivers were not recovered; neither these
script snapshots nor 6-seed sensitivity tests reproduce all 3,582 null fits.

Source code copyright and any upstream copied logic require manual review.
Do not infer rights to publish upstream datasets or downloaded scripts from
these historical research artifacts.
